# 生日祝福网站

这是一个专为特殊的人设计的生日祝福网站。在她生日到来之前，网站会显示精美的倒计时；当生日到来时（5月29日），网站会自动切换为祝福模式，展示特别的生日祝福内容，持续三天。

## 功能特点

- **智能日期检测**：自动识别当前日期与生日的关系
- **浪漫倒计时**：距离生日还有多少天、小时、分钟和秒
- **星空背景**：带有闪烁星星和随机流星的动态背景
- **生日祝福**：当到达生日日期时，展示温馨的祝福内容
- **互动礼物盒**：可点击打开的动画礼物盒
- **爱心树**：可互动的爱心树动画
- **祝福卡片**：可翻转的生日祝福卡片
- **许愿蜡烛**：可吹灭的生日蜡烛动画
- **生日蛋糕**：全屏蛋糕视频板块，配"生日快乐"脉冲标题
- **粒子玫瑰**：全屏玫瑰视频板块，纯画面无文字，向朋友送出的一整束心意
- **漂浮爱心**：生日模式下特有的漂浮爱心效果
- **烟花效果**：庆祝生日的动态烟花
- **背景音乐**：可控制的背景音乐功能
- **响应式设计**：适配各种设备尺寸，从手机到桌面电脑

## 使用技术

- HTML5
- CSS3 (动画、过渡效果、响应式设计)
- JavaScript (原生JS)
- Canvas (星空、爱心树、烟花动画)
- Web Audio API (背景音乐控制)
- Google Fonts (字体优化)

## 自定义指南

### 基本自定义

1. **修改生日日期**：编辑`js/script.js`文件中的生日设置
   ```javascript
   const BIRTHDAY_MONTH = 4; // JavaScript中月份从0开始，所以5月是4
   const BIRTHDAY_DAY = 29;
   ```

2. **更改祝福文字**：编辑`index.html`中的相关内容
   - 倒计时标题：搜索"title"类元素
   - 生日祝福：搜索"birthday-message"类元素
   - 祝福卡片：搜索"wish-card-back"类元素
   - 视频板块标题：搜索"video-caption"类元素（**目前仅蛋糕板块有标题，玫瑰板块已去除全部文字**）

3. **更换背景音乐**：
   - 将您喜欢的音乐文件放入`assets/audio/`目录
   - 重命名为`birthday-music.mp3`（推荐同时提供ogg格式提高兼容性）
   - 或修改`index.html`中的音频源路径

4. **更换视频板块素材**：
   - 将视频放入`assets/videos/`目录，命名为`cake.mp4` / `rose.mp4`
   - 或修改`index.html`中`#cake-section`、`#rose-section`里`<source>`的路径
   - **务必同步修改对应 section 的 `data-video-ar` 与 `--video-ar`**（视频宽高比，
     如蛋糕 `720 / 924`）。竖屏下视频盒按这个比例收缩，比例写错会导致画面留白或裁切。
   - 蛋糕板块有**两份指向同一 mp4 的 `<video>`**（模糊背景 + 主体），
     换素材时两处 `<source>` 都要改
   - 视频为静音循环播放，无需与`#bgm`背景音乐同步

5. **更换分段音乐**：
   - 首段音乐：`assets/audio/birthday-music.mp3`
   - 第二段音乐：`assets/audio/only one AKA.MP3`
   - 切换点与对应文件在 `script.js` 的 `TRACKS` 对象里配置（按 section id 索引），
     要改哪一段放哪首直接改这里；`INITIAL_TRACK` 是首段音乐
   - 新增音源时注意把 `#bgm-next` 预加载器的 `src` 一并更新

## iPhone / Safari 适配说明

本项目针对 iOS Safari 做了专门处理，改动这些地方时请注意：

1. **视频内联自动播放**
   - 视频必须同时满足 `muted` + `playsinline` 才能自动播放；`script.js` 的
     `initSectionVideos()` 会在运行时再设置一次 DOM 属性（部分老版本只认属性）
   - 首次用户手势（`touchstart`/`click`/`keydown`）会统一重试播放，
     用于"被自动播放策略拦截"后的恢复
   - 切后台回来、Safari 往返缓存恢复（`pageshow`）、`focus` 时都会重新 `play()`

2. **音频播放**
   - Safari 不允许无手势自动播放音频，也**无法用代码绕过**。做法是：
     首次手势（`touchstart`/`click`/`keydown`）里直接调 `playBgm()`——
     `play()` 成功即完成解锁；失败（源未就绪等）会被 `bgmWantPlay` 记住，
     由 `canplay` 等就绪事件和有限次重试补播
   - 不采用"先 play 再 pause"的解锁写法：它的 cleanup `pause` 会排在
     `playBgm()` 的 `play` 之后（同一 microtask 结算），把刚起的音乐掐断
   - 自动播放被拦时显示提示气泡，引导用户点右下角 ♪

3. **视口高度用 `svh` 而非 `vh`**
   - iOS Safari 地址栏收起/展开时 `100vh` 会大于可视高度，导致 section 比屏幕高、
     视频溢出。`.video-section` 使用 `100svh`（带 `100vh` 回退），高度稳定不跳动

4. **视频比例与裁切（重要）**
   - **蛋糕用 `contain`**：素材是 720×924 竖屏，横屏桌面若用 `cover` 铺满必须
     放大到视口宽度，画面被裁掉约 64%（蜡烛、蛋糕顶、花体字全看不见），
     这就是"蛋糕过于大"的原因。`contain` 保证整块蛋糕始终完整
   - 实测该素材主体横向占满 92%~98% 画面宽度且居中，**无法靠左右裁切瘦身**，
     所以只能 `contain` + 填充留白，不能改 `cover`
   - **留白用模糊背景视频填充**：`#cake-section` 内放了两份同源 video——
     `.video-backdrop`（`cover` 放大 + `blur(32px)`，负责填满）和
     `.section-video`（`contain`，负责清晰显示蛋糕）。
     两个 `<video>` 指向同一个 mp4，浏览器只下载一次，不增加流量
   - 层级：`.video-backdrop`(0) < `#cake-section::before` 渐变(1) <
     `.section-video`(2) < `.video-caption`(3)
   - **玫瑰用 `cover`**：素材是 2006×1080 横屏。桌面比例接近，裁切很小；
     竖屏下会裁掉约 78%，但画面主体（花与花茎）居中，观感完整，
     所以 `@media (orientation: portrait)` 下直接铺满
   - 玫瑰板块**不含任何文字**，因此没有加暗罩，粒子画面以原始亮度呈现；
     如需在玫瑰上叠字，记得补一层暗罩否则白色标题在亮部会看不清

5. **声音来源只有一个**
   - 所有视频板块**强制静音**：`muted` + `volume = 0`，
     且每次 `play`/`playing` 事件都会重新确认一次（`enforceSilent()`），
     即使以后换成带音轨的素材（包括模糊背景那份）也不会出声
   - 持续声音只来自 `#bgm`，按段落切歌（见下）
   - 两个交互瞬时音效（吹蜡烛、烟花爆开）用 Web Audio 现场合成，
     不依赖任何音频文件；原代码用 `new Audio()` 但没设 `src`，
     在所有浏览器上都必然失败并报 `NotAllowedError`

6. **分段背景音乐**
   - 封面/许愿阶段：`assets/audio/birthday-music.mp3`
   - **进入蛋糕段起**：切成 `assets/audio/only one AKA.MP3`，玫瑰段沿用，
     滚回前面的段落不会切回去
   - 切歌依据是"哪个 section 占据视口中心"，见 `setupMusicSwitching()`。
     **注意页面真正的滚动容器是 `#birthday-container`（`overflow: auto`），
     不是 `window`**，所以滚动监听挂在它上面；同时 `window` 也挂了一份以兼容
     将来改成整页滚动
   - 换源实现（`switchTrack()`）：改 `<source>`/`src` 后 `load()`，
     再等就绪补播，避免静音空档。iOS 上音频只需解锁一次，换源后仍可直接播放
   - `<audio>` 已不写死 `src`，初始音源在首次手势时由 `unlockAudio()` 设置
   - `#bgm-next` 是第二首的预加载器（`preload="auto"`），不参与播放，
     只为切歌时少一次等待

7. **安全区**
   - `viewport` 已设置 `viewport-fit=cover`，标题容器用
     `env(safe-area-inset-*)` 避开刘海与底部小黑条

8. **封面页声音提示**
   - 右下角 ♪ 按钮上方常驻一个气泡「🔊 点右下角的 ♪ 打开声音」，带指向箭头
   - 音乐一旦播放成功、或离开封面页进入生日祝福，气泡自动淡出
   - 自动播放被拦时会重新亮起，引导用户手动点

## 常见问题与排查

1. **音乐无法自动播放**
   - 原因：浏览器策略限制，多数浏览器禁止自动播放音频
   - 解决：添加用户交互触发音乐，已实现点击页面播放功能

2. **日期检测不准确**
   - 原因：可能是时区设置问题
   - 解决：检查`script.js`中的日期处理代码，确保使用本地时间

3. **动画效果卡顿**
   - 原因：Canvas动画在低性能设备上可能消耗较多资源
   - 解决：减少星星数量或调整动画复杂度，相关参数在`script.js`中

4. **移动设备显示异常**
   - 原因：可能是响应式设计未完全适配特定设备
   - 解决：检查`style.css`中的媒体查询设置，针对问题设备尺寸添加特定样式

## 注意事项

- **浏览器兼容性**：网站设计已考虑主流现代浏览器，但在IE等旧浏览器中可能无法正常显示
- **背景音乐**：需要用户点击页面后才能播放（浏览器策略限制）
- **资源文件**：确保图片和音频文件大小适中，以保证加载速度
- **时间设置**：生日日期设置在JS中，注意月份是从0开始计数（5月应设为4）
- **持续时间**：生日祝福模式设计为持续三天（生日当天及之后两天）
- **本地测试**：直接打开HTML文件测试时，某些功能可能因浏览器安全策略受限
